## File naming

| Pattern | Meaning | Example |
|---|---|---|
| `C.S.topic.py` | Worked example from chapter **C**, section **S** | `4.6.list_comprehension.py` |
| `0.C.N.ex.py` | My answer to "Try It Yourself" exercise **C-N** | `0.4.10.ex.py` → exercise 4-10 |

## Running

Every file is a standalone script:

```bash
python "004.Working with Lists/4.6.list_comprehension.py"
```

The `.idea/` folder and `.iml` file are PyCharm project settings.
